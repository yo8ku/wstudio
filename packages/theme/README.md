# @note-studio/theme

Note Studio 主题系统模块，专注于主题系统功能。

## 功能模块

### 🎨 主题系统

提供完整的主题管理功能，包括主题注册、应用、Monaco Editor 集成等。

主要功能：

- 主题注册与管理
- Monaco Editor 主题集成
- DOM 主题应用（CSS 变量）
- 内置主题支持（Dark+、Light+）
- 主题搜索与筛选

## 安装

```bash
cd packages/theme
npm install
npm run build
```

## 开发

```bash
# 监听模式
npm run watch

# 构建
npm run build

# 清理
npm run clean
```
