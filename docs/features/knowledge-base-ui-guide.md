# 知识库 UI 使用指南

## 📖 访问知识库

### 步骤 1: 点击活动栏图标

在左侧活动栏找到并点击**知识库图标** 📖 (书本图标)

```
活动栏位置（左侧边栏）:
┌─────┐
│ 📁  │  资源管理器
│   │  搜索
│ 🔀  │  源代码管理  
│ 📦  │  扩展
│ 📖  │ ← 点击这里！(知识库)
│ 🤖  │  AI 模型
│ ⚙️  │  设置
└─────┘
```

### 步骤 2: 查看侧边栏

点击后，右侧会展开知识库侧边栏面板。

## 🎨 界面布局

### 完整界面结构

```
┌────────────────────────────────────┐
│          知识库                 [×] │  ← 标题栏（可关闭）
├────────────────────────────────────┤
│   [搜索知识库...]                │  ← 搜索框
├────────────────────────────────────┤
│  [ 浏览 ] [ 搜索 ] [ 导入 ]        │  ← 标签栏
├────────────────────────────────────┤
│                                    │
│                                    │
│        内容区域                    │  ← 主内容区
│      (根据选中标签变化)            │
│                                    │
│                                    │
├────────────────────────────────────┤
│    [🔄 刷新]        [⚙️ 设置]     │  ← 操作栏
└────────────────────────────────────┘
```

## 🏷️ 标签页功能

### 1️⃣ 浏览标签

展示知识库的树形结构。

**界面示例:**
```
 [搜索知识库...]
─────────────────────
[ 浏览 | 搜索 | 导入 ]
─────────────────────

📁 技术文档          ◀ 文件夹（点击展开/收起）
  └ 📄 React 开发指南 (5k)     ◀ 文档（显示字数）
  └ 📄 TypeScript 最佳实践 (3k)

📁 项目笔记
  └ 📄 架构设计 (2k)
```

**交互说明:**
- 点击 📁 **文件夹** → 展开/收起子项
- 点击 📄 **文档** → 在编辑器中打开
- 数字 (如 5k) → 表示文档字数（5000字）

### 2️⃣ 搜索标签

搜索知识库内容并显示结果。

**界面示例:**
```
 [React Hooks]      ◀ 输入搜索词
─────────────────────
[ 浏览 | 搜索 | 导入 ]
─────────────────────

搜索结果:

┌─────────────────────────────┐
│ React Hooks 使用            │  ◀ 匹配标题
│ ...useState 和 useEffect    │  ◀ 上下文预览
│ 是最常用的 Hooks...         │
│ 来自: React 开发指南        │  ◀ 来源文档
└─────────────────────────────┘

┌─────────────────────────────┐
│ 组件设计原则                │
│ ...单一职责原则在组件       │
│ 设计中非常重要...           │
│ 来自: 架构设计              │
└─────────────────────────────┘
```

**交互说明:**
- 在搜索框输入关键词
- 实时显示搜索结果
- 点击结果卡片 → 打开源文档

### 3️⃣ 导入标签

导入新的知识内容到知识库。

**界面示例:**
```
 [搜索知识库...]
─────────────────────
[ 浏览 | 搜索 | 导入 ]
─────────────────────

导入选项:

┌─────────────────────────────┐
│  📁  导入文件夹              │  ◀ 批量导入
└─────────────────────────────┘

┌─────────────────────────────┐
│  📄  导入文件                │  ◀ 单个文件
└─────────────────────────────┘

┌─────────────────────────────┐
│  🌐  导入网页                │  ◀ 从网页导入
└─────────────────────────────┘

最近导入:
  项目文档 (2024-01-20)       ◀ 导入历史
  技术笔记 (2024-01-15)
```

**交互说明:**
- 点击 **导入文件夹** → 选择文件夹批量导入
- 点击 **导入文件** → 选择单个文件
- 点击 **导入网页** → 输入 URL 导入

## 🔧 底部操作栏

### 刷新按钮 🔄
- 点击刷新知识库内容
- 同步最新的文档变化

### 设置按钮 ⚙️
- 配置知识库设置
- 调整索引选项
- 管理存储位置

## 💡 使用技巧

### 快速搜索
1. 点击顶部搜索框
2. 输入关键词
3. 按 `Enter` 或切换到"搜索"标签
4. 查看搜索结果

### 浏览文档
1. 切换到"浏览"标签
2. 点击文件夹展开
3. 点击文档打开

### 导入内容
1. 切换到"导入"标签
2. 选择导入方式
3. 选择文件/文件夹/输入URL
4. 等待导入完成

##  快捷键（建议）

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 打开知识库 | `Ctrl+Shift+K` | 显示/隐藏知识库面板 |
| 聚焦搜索框 | `Ctrl+F` | 快速搜索 |
| 刷新知识库 | `Ctrl+R` | 刷新内容 |
| 关闭面板 | `Esc` | 关闭侧边栏 |

> 注：快捷键可在设置中自定义

## 🌈 主题适配

知识库面板完全支持应用程序主题：

### 深色主题
- 暗色背景，减少眼睛疲劳
- 高对比度图标和文字
- 柔和的边框和分隔线

### 浅色主题
- 明亮背景，清晰易读
- 温和的配色方案
- 清晰的层次结构

## 📱 响应式布局

### 侧边栏宽度调整
1. 将鼠标移到侧边栏右边缘
2. 光标变为 ↔ 调整符号
3. 拖动调整宽度
4. 释放鼠标固定宽度

### 自动收缩
- 拖动宽度小于 150px 时自动关闭
- 最小宽度: 200px
- 最大宽度: 600px
- 默认宽度: 256px

## ❓ 常见问题

### Q: 如何快速定位某个文档？
**A:** 使用顶部搜索框输入文档名称，然后在搜索结果中点击。

### Q: 文档后面的数字是什么意思？
**A:** 数字表示文档的字数统计。例如 "5k" 表示约 5000 字。

### Q: 如何批量导入文档？
**A:** 切换到"导入"标签，点击"导入文件夹"，选择包含文档的文件夹。

### Q: 搜索结果为什么显示不完整？
**A:** 搜索结果显示的是匹配片段的上下文预览。点击结果可查看完整文档。

### Q: 如何关闭知识库面板？
**A:** 点击标题栏的 × 按钮，或再次点击活动栏的知识库图标。
