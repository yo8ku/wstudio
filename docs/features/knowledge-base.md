# 知识库功能说明

## 概述

知识库是 Note Studio 的核心功能之一，用于管理和检索笔记、文档等知识内容。它提供了强大的搜索、分类和组织功能，帮助用户高效管理知识资产。

## 功能特性

### 📚 知识浏览

- **树形结构**: 以文件夹和文档的层级结构展示知识库内容
- **快速定位**: 支持展开/收起文件夹，快速定位目标文档
- **元数据显示**: 显示文档的字数、修改时间、标签等信息

###  智能搜索

- **全文搜索**: 在所有文档中搜索关键词
- **结果预览**: 显示匹配的文档片段上下文
- **来源追踪**: 显示搜索结果的来源文档
- **实时建议**: 输入时提供搜索建议

### 📥 内容导入

支持多种方式导入知识内容：

1. **文件夹导入**: 批量导入整个文件夹的文档
2. **文件导入**: 导入单个文档文件
3. **网页导入**: 从网页抓取内容并保存

## 使用指南

### 打开知识库

1. 点击左侧活动栏的 📖 知识库图标
2. 侧边栏将显示知识库管理面板

### 浏览知识

1. 切换到"浏览"标签
2. 点击文件夹展开查看子项
3. 点击文档打开查看详细内容
4. 文档右侧显示字数统计（如 "5k" 表示 5000 字）

### 搜索知识

1. 切换到"搜索"标签
2. 在顶部搜索框输入关键词
3. 查看搜索结果列表
4. 点击结果项查看完整文档

### 导入内容

1. 切换到"导入"标签
2. 选择导入方式：
   - **导入文件夹**: 选择文件夹批量导入
   - **导入文件**: 选择单个文件导入
   - **导入网页**: 输入网页 URL 导入
3. 查看"最近导入"了解导入历史

## 技术实现

### 前端组件

知识库功能由以下组件实现：

- `KnowledgeBase.tsx`: 主组件，包含浏览、搜索、导入三个标签
- 集成在 `Sidebar.tsx` 中，作为侧边栏视图之一
- 通过 `ActivityBar.tsx` 的知识库按钮激活

### 后端集成

知识库前端界面使用 `electron-store` 进行本地数据存储，未来可以与 `@note-studio/global-rag` 包集成以实现 RAG 功能。

### 数据结构

```typescript
interface KnowledgeItem {
  id: string;              // 唯一标识
  title: string;           // 标题
  type: 'folder' | 'document' | 'chunk';  // 类型
  children?: KnowledgeItem[];  // 子项（文件夹）
  path?: string;           // 文件路径
  metadata?: {
    wordCount?: number;    // 字数
    lastModified?: Date;   // 修改时间
    tags?: string[];       // 标签
  };
}
```

## 常见问题

### Q: 如何导入大量文档？
A: 使用"导入文件夹"功能，选择包含所有文档的文件夹，系统会自动批量导入。

### Q: 搜索速度慢怎么办？
A: 知识库会为文档建立索引。首次搜索可能较慢，后续搜索会更快。建议定期刷新知识库。

### Q: 支持哪些文档格式？
A: 目前支持 Markdown、文本文件。未来将支持 PDF、Word、HTML 等更多格式。

### Q: 知识库数据存储在哪里？
A: 知识库数据存储在本地，路径可在设置中配置。默认为用户数据目录下的 `knowledge-base` 文件夹。
