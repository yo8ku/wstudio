# 快速开始

欢迎使用 Note Studio！本指南将帮助你快速上手。

## 安装

### 下载应用

从 [GitHub Releases](https://github.com/yo8ku/WiseAI-Note-Studio/releases) 下载最新版本。

### 系统要求

- **Windows**: Windows 10 或更高版本
- **macOS**: macOS 10.15 或更高版本
- **Linux**: 支持 AppImage

## 首次使用

### 1. 启动应用

双击应用图标启动 Note Studio。

### 2. 选择工作区

首次启动时，你需要选择或创建一个工作区：

1. 点击"打开文件夹"
2. 选择一个空文件夹作为工作区
3. 或者创建一个新文件夹

### 3. 创建第一个笔记

1. 在侧边栏右键点击
2. 选择"新建文件"
3. 输入文件名（例如：`hello.md`）
4. 开始编写内容

## 基本功能

### Markdown 编辑

Note Studio 支持完整的 Markdown 语法：

\`\`\`markdown
# 标题 1
## 标题 2
### 标题 3

- 列表项 1
- 列表项 2

**粗体** 和 *斜体*

[链接](https://example.com)
\`\`\`

### 快捷键

常用快捷键：

- `Ctrl/Cmd + S` - 保存
- `Ctrl/Cmd + N` - 新建文件
- `Ctrl/Cmd + P` - 命令面板
- `Ctrl/Cmd + ,` - 打开设置

更多快捷键请查看[快捷键指南](../keyboard-shortcuts-guide.md)。

### 主题切换

1. 点击菜单栏的主题图标
2. 选择你喜欢的主题
3. 主题会立即应用

## 高级功能

### AI 助手

配置 AI 助手：

1. 打开设置 (Ctrl/Cmd + ,)
2. 找到"AI 配置"
3. 添加你的 API 密钥
4. 选择模型

### 知识库

启用知识库功能：

1. 打开命令面板 (Ctrl/Cmd + P)
2. 输入"知识库"
3. 按照提示配置

详细说明请查看[知识库指南](./features/knowledge-base.md)。

### 扩展

安装扩展：

1. 点击侧边栏的扩展图标
2. 浏览扩展市场
3. 点击"安装"按钮
